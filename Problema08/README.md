# Problema08

Problema 08. Vocal o consonante
Estructura elegida

if - else if - else.

Justificación

Se utiliza esta estructura para verificar primero que la entrada sea una letra minúscula y después identificar si es vocal o consonante.

Pruebas de ejecución
Prueba 1: Vocal

Entrada: e

Salida esperada:

Ingrese una letra minúscula: e
Es vocal

Prueba 2: Consonante

Entrada: m

Salida esperada:

Ingrese una letra minúscula: m
Es consonante

Prueba 3: Número

Entrada: 7

Salida esperada:

Ingrese una letra minúscula: 7
No es una letra
