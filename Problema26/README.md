# Problema26

Problema 26. Peaje
Estructura elegida

switch con excepciones mediante throw y manejo con try-catch.

Justificación

Se utiliza switch para seleccionar la tarifa correspondiente a cada categoría de vehículo y una excepción para informar cuando la categoría es desconocida.

Pruebas de ejecución
Prueba 1: Moto

Entrada: M.

Salida esperada:

Ingrese la categoría del vehículo (M, A, B, C): M
Categoría M - Tarifa: $0

Prueba 2: Automóvil

Entrada: A.

Salida esperada:

Ingrese la categoría del vehículo (M, A, B, C): A
Categoría A - Tarifa: $12.000

Evidencia

Guardar las capturas de las ejecuciones en evidencias
