# Problema14

Problema 14. Estado del aprendiz
Estructura elegida

Operador ternario (?:).

Justificación

Se utiliza el operador ternario porque permite asignar el estado académico en una sola línea: aprobado si la nota es igual o superior a 3,0 y reprobado en caso contrario.

Pruebas de ejecución
Prueba 1: Aprendiz aprobado

Entrada: 3,5

Salida esperada:

Ingrese la nota final (0 a 5): 3,5
Nota: 3,5 - Aprobado

Prueba 2: Aprendiz reprobado

Entrada: 2,9

Salida esperada:

Ingrese la nota final (0 a 5): 2,9
Nota: 2,9 - Reprobado
