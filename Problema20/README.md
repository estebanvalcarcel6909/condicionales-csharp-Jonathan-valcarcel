# Problema20

Problema 20. Días de cada mes
Estructura elegida

switch.

Justificación

Se utiliza switch porque permite agrupar los meses que tienen 31 días, 30 días o 28 días en un año no bisiesto.

Pruebas de ejecución
Prueba 1: Abril

Entrada: 4

Salida esperada:

Ingrese el número del mes (1-12): 4
30 días

Prueba 2: Febrero

Entrada: 2

Salida esperada:

Ingrese el número del mes (1-12): 2
28 días

Prueba 3: Diciembre

Entrada: 12

Salida esperada:

Ingrese el número del mes (1-12): 12
31 días

Prueba 4: Mes inválido

Entrada: 13

Salida esperada:

Ingrese el número del mes (1-12): 13
Mes inválido

Prueba 5: Número negativo

Entrada: -1

Salida esperada:

Ingrese el número del mes (1-12): -1
Mes inválido
