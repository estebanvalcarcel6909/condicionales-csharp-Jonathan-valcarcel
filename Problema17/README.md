# Problema17

Problema 17. Control de un reproductor
Estructura elegida

switch.

Justificación

Se utiliza switch porque permite ejecutar una acción diferente según el comando de texto recibido.

Pruebas de ejecución
Prueba 1: Play

Entrada: play

Salida esperada:

Ingrese un comando (play, pause, stop, next): play
Reproduciendo...

Prueba 2: Pause

Entrada: pause

Salida esperada:

Ingrese un comando (play, pause, stop, next): pause
En pausa

Prueba 3: Stop

Entrada: stop

Salida esperada:

Ingrese un comando (play, pause, stop, next): stop
Detenido

Prueba 4: Next

Entrada: next

Salida esperada:

Ingrese un comando (play, pause, stop, next): next
Siguiente canción

Prueba 5: Comando desconocido

Entrada: rewind

Salida esperada:

Ingrese un comando (play, pause, stop, next): rewind
Comando no reconocido

Evidencia

Guardar la captura de la ejecución en evidencias
