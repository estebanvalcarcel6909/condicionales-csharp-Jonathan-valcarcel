# Problema16

Problema 16. Ubicación de un dron
Estructura elegida

if - else if - else con condiciones compuestas.

Justificación

Se utiliza esta estructura para identificar el origen, los ejes y los cuatro cuadrantes según los signos de las coordenadas X y Y.

Pruebas de ejecución
Prueba 1: Primer cuadrante

Entrada: X = 3, Y = 4.

Salida esperada:

Ingrese la coordenada X: 3
Ingrese la coordenada Y: 4
Primer cuadrante

Prueba 2: Tercer cuadrante

Entrada: X = -2, Y = -7.

Salida esperada:

Ingrese la coordenada X: -2
Ingrese la coordenada Y: -7
Tercer cuadrante

Prueba 3: Origen

Entrada: X = 0, Y = 0.

Salida esperada:

Ingrese la coordenada X: 0
Ingrese la coordenada Y: 0
Origen

Prueba 4: Sobre un eje

Entrada: X = 0, Y = 5.

Salida esperada:

Ingrese la coordenada X: 0
Ingrese la coordenada Y: 5
Sobre un eje

Prueba 5: Cuarto cuadrante

Entrada: X = 4, Y = -3.

Salida esperada:

Ingrese la coordenada X: 4
Ingrese la coordenada Y: -3
Cuarto cuadrante
