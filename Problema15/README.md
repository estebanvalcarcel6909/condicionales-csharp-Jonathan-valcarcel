# Problema15

Problema 15. Índice de masa corporal
Estructura elegida

if - else if - else.

Justificación

Se utiliza esta estructura porque permite clasificar el IMC según los diferentes rangos establecidos.

Pruebas de ejecución
Prueba 1: Peso normal

Entrada: peso 70, estatura 1.75.

Salida esperada:

Ingrese el peso en kg: 70
Ingrese la estatura en metros: 1.75
IMC: 22.9 - Peso normal

Prueba 2: Bajo peso

Entrada: peso 50, estatura 1.75.

Salida esperada:

Ingrese el peso en kg: 50
Ingrese la estatura en metros: 1.75
IMC: 16.3 - Bajo peso
