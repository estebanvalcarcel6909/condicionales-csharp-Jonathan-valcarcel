# Problema12

Problema 12. Aprobación de crédito
Estructura elegida

if - else anidado.

Justificación

Se utiliza esta estructura porque primero se comprueba si el solicitante tiene empleo y después se clasifica el crédito según su ingreso mensual.

Pruebas de ejecución
Prueba 1: Sin empleo

Entrada: no

Salida esperada:

¿Tiene empleo? (si/no): no
Crédito rechazado

Prueba 2: Con empleo e ingreso alto

Entrada: si, 3000000

Salida esperada:

¿Tiene empleo? (si/no): si
Ingrese su ingreso mensual: 3000000
Crédito alto aprobado

Prueba 3: Con empleo e ingreso básico

Entrada: si, 1800000

Salida esperada:

¿Tiene empleo? (si/no): si
Ingrese su ingreso mensual: 1800000
Crédito básico aprobado

Evidencia

Guardar las capturas de ejecución en la carpeta evidencias
