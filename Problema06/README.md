# Problema06

Problema 06. Piedra, papel o tijera

Estructura elegida: if - else if - else.

Justificación: Se utiliza para comparar las jugadas de los dos jugadores y determinar quién gana o si hay empate.

Código de prueba
Prueba 1

Entrada: piedra, tijera

Salida esperada:

Ingrese la jugada del jugador 1: piedra
Ingrese la jugada del jugador 2: tijera
Gana el jugador 1

Prueba 2

Entrada: piedra, papel

Salida esperada:

Ingrese la jugada del jugador 1: piedra
Ingrese la jugada del jugador 2: papel
Gana el jugador 2

Prueba 3

Entrada: papel, papel

Salida esperada:

Ingrese la jugada del jugador 1: papel
Ingrese la jugada del jugador 2: papel
Empate
