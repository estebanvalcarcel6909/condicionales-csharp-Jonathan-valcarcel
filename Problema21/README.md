# Problema21

Problema 21. Carrito de compras
Estructura elegida

Operador ternario (?:).

Justificación

Se utiliza el operador ternario para seleccionar el singular o plural de la palabra «artículo» según la cantidad y construir el mensaje en una sola asignación.

Pruebas de ejecución
Prueba 1: Un artículo

Entrada: 1

Salida esperada:

Ingrese la cantidad de artículos: 1
Tienes 1 artículo en el carrito

Prueba 2: Tres artículos

Entrada: 3

Salida esperada:

Ingrese la cantidad de artículos: 3
Tienes 3 artículos en el carrito

Prueba 3: Ningún artículo

Entrada: 0

Salida esperada:

Ingrese la cantidad de artículos: 0
Tienes 0 artículos en el carrito
