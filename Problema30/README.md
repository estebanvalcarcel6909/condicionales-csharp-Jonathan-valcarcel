# Problema30

Problema 30. Boletín de calificaciones (integrador)
Estructura elegida

if - else if - else, switch y operador ternario (?:).

Justificación

Se utilizan estas estructuras para clasificar el promedio, asignar una letra, seleccionar la retroalimentación, determinar si el aprendiz aprobó y comprobar si merece mención de honor.

Pruebas de ejecución
Prueba 1: Buen desempeño, letra B

Entrada: notas 85, 78, 92.

Salida esperada:

Ingrese la primera nota (0-100): 85
Ingrese la segunda nota (0-100): 78
Ingrese la tercera nota (0-100): 92
Promedio: 85,0 | Letra: B | Buen desempeño, sigue así | Aprobado

Prueba 2: Desempeño excelente

Entrada: notas 95, 90, 100.

Salida esperada:

Ingrese la primera nota (0-100): 95
Ingrese la segunda nota (0-100): 90
Ingrese la tercera nota (0-100): 100
Promedio: 95,0 | Letra: A | Desempeño excelente | Aprobado
