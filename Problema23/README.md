# Problema23

Problema 23. Inicio de sesión
Estructura elegida

if - else anidado.

Justificación

Se utiliza esta estructura porque el sistema debe comprobar primero el usuario y después la contraseña, mostrando un mensaje diferente para cada error.

Pruebas de ejecución
Prueba 1: Inicio de sesión correcto

Entrada: usuario aprendiz, contraseña Sena2026.

Salida esperada:

Ingrese el usuario: aprendiz
Ingrese la contraseña: Sena2026
Bienvenido

Prueba 2: Usuario inexistente

Entrada: usuario estudiante.

Salida esperada:

Ingrese el usuario: estudiante
Usuario no encontrado

Prueba 3: Contraseña incorrecta

Entrada: usuario aprendiz, contraseña 123456.

Salida esperada:

Ingrese el usuario: aprendiz
Ingrese la contraseña: 123456
Contraseña incorrecta
