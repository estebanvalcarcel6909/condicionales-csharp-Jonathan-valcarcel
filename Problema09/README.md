# Problema09

Problema 09. Año bisiesto
Estructura elegida

if - else con operadores lógicos.

Justificación

Se utiliza esta estructura porque la condición de año bisiesto combina reglas de divisibilidad mediante los operadores lógicos && y ||.

Pruebas de ejecución
Prueba 1: Año 2024

Entrada: 2024

Salida esperada:

Ingrese un año: 2024
Bisiesto

Prueba 2: Año 1900

Salida esperada:

Ingrese un año: 1900
No bisiesto
