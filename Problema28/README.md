# Problema28

Problema 28. Descuento por compra
Estructura elegida

if - else if - else con condiciones compuestas.

Justificación

Se utiliza esta estructura para asignar el descuento según el valor de la compra y sumar un 5 % adicional cuando el cliente es frecuente y compra por lo menos $100.000.

Pruebas de ejecución
Prueba 1: Compra de $250.000 con cliente frecuente

Entrada: compra 250000, frecuente si.

Salida esperada:

Ingrese el valor de la compra: 250000
¿Es cliente frecuente? (si/no): si
Valor de la compra: $250.000
Descuento total: 15%
Total a pagar: $212.500

Prueba 2: Compra de $250.000 sin ser cliente frecuente

Entrada: compra 250000, frecuente no.

Salida esperada:

Ingrese el valor de la compra: 250000
¿Es cliente frecuente? (si/no): no
Valor de la compra: $250.000
Descuento total: 10%
Total a pagar: $225.000
